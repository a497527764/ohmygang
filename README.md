# 钢一下

以英雄联盟「心之钢」为主题的去中心化群聊：局域网直连加公共中继，不需要自建服务器；连发消息叠心之钢层数。Windows 桌面应用，Tauri 2（Rust 核心 + React 界面）。

## 安装和使用

1. 运行安装包 `lolgang_<版本>_x64-setup.exe`（在 `src-tauri/target/release/bundle/nsis/` 里），按当前用户安装，不需要管理员权限。装好后开始菜单和「应用」列表里显示「钢一下」。
2. 第一次运行时 Windows 防火墙会询问，请勾选「专用网络」并允许，否则同一局域网的群友找不到你。
3. 点「聊天」右上角的新建按钮建一个群，房间码会自动复制，发给群友；群友点同一个按钮选「用房间码进群」粘贴即可加入。
4. 点最左边窄栏底部自己的头像打开个人资料：改昵称、选内置头像或上传图片做头像，群友都能看到。
5. 5 秒内连发 3 条消息叠一层心之钢（规则群主可改）。头像右下角是层数，群资料里有排行榜。
6. 聊天：输入框左边可以发表情、发图片（也能直接粘贴或拖进来），输入 @ 可以选人；右键气泡（或点气泡右上角的小箭头）可以回复、复制、@TA；右上角放大镜搜索记录，点群名打开群资料，点消息区空白处关掉。
7. 右键群列表里的群：置顶、免打扰、清空聊天记录、退出群聊、删除聊天。删除聊天只影响本机：还在的群从列表移除，来了新消息会重新出现；已退出或已解散的群会删掉本机记录。
8. 点窗口的关闭按钮只会收进右下角托盘，程序继续收消息，来了新消息托盘图标会出现红点；要彻底退出，右键托盘图标选「退出」。
9. 换电脑前在「设置 → 备份与恢复」导出备份，文件在「文档\钢一下备份」。设置里还能切换浅色、深色主题。

从旧版「心之钢群聊」升级：先在「设置 → 应用」里卸载「心之钢群聊」（不会删聊天数据），再装「钢一下」。两者产品名不同，不卸载会并存。

## 开发

```bash
pnpm install
pnpm tauri dev
cd src-tauri && cargo test --lib
pnpm release
```

`pnpm release` 先运行 `pnpm tauri build` 生成 NSIS 安装包（第一次运行会从 GitHub 下载 NSIS 工具），再把安装包改名为 `lolgang_<版本>_x64-setup.exe`。版本号在 `src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml`、`package.json` 三处，发版时一起改。

第一次运行时 Windows 防火墙会询问是否允许联网，请勾选「专用网络」并允许，否则收不到局域网里其他人的消息。

### 单机双开（开发用）

一台电脑上开两个实例互相测试：先用 `pnpm tauri dev` 开第一个，再在另一个 PowerShell 窗口里运行：

```powershell
$env:LOLGANG_INSTANCE = '2'; & '.\src-tauri\target\debug\lolgang.exe'
```

第二个实例使用独立的数据目录、凭据条目和 UDP 端口（47481）。开发版的广播同时发往两个端口，所以两个实例能互相发现。
