# 钢一下 2.0 — 需求

> 状态：草案（2026-11-03 第三版），等所有者审阅。1.x 的需求见 [../requirements.md](../requirements.md)，2.0 起不再沿用。
> 第二版改动：自动更新、macOS 版、Linux 版从「不做」改为「要做」（所有者 2026-11-03）。
> 第三版改动：所有者没有 Mac 和 Linux 设备，正式支持只有 Windows；macOS、Linux 照 lolPing 的做法实现，出「实验版，未测试」的安装包，不做真机验收（所有者 2026-11-03）。

## 1. 一句话

一个常驻桌面的英雄联盟小玩具：按住 Alt 拖动，在屏幕任何地方发英雄联盟的信号；按住 Ctrl 拖动放表情；和队友组队后，你发的信号、表情会出现在队友的屏幕上。开了「对线模式」，队友的鼠标会变成你屏幕上的小英雄，你贴近他、充能、出手，就能叠一层心之钢。正式支持 Windows；另出 macOS 和 Linux 的实验版安装包（未经测试）；能自动更新。

2.0 不再是聊天软件：1.x 的聊天、发图、搜索记录都去掉。

## 2. 背景和来源

- 玩法和交互参考开源项目 [lolPing](https://github.com/darrenprx/lolPing)（MIT 许可，作者 Danrui Meng）。所有者 2026-11-03 决定把它的主要功能用 Rust 重写进本项目。
- 心之钢的原版机制：靠近敌人 700 码停留 3 秒充能，普攻或技能命中敌人就叠一层；同一个目标 30 秒冷却；团战可以对多个目标分别叠；每层获得造成伤害 10% 的永久生命值。

## 3. 所有者已定的决定（2026-11-03）

| 事项 | 决定 |
|---|---|
| 聊天 | 去掉。1.x 的聊天、发图、引用、@、搜索记录、清空记录都不要 |
| 从 lolPing 搬的功能 | 信号轮盘；表情轮盘（含自己导入的图片表情）；Tab 队伍面板和投票（准备确认、投降、踢人）；Alt+T 在屏幕上打一行字；自动更新；macOS 版；Linux 版 |
| 不搬的 | AI 队友、网页演示 |
| 素材 | 和 lolPing 一样，直接使用它从英雄联盟提取的信号图标、音效、表情和界面图。版权归 Riot Games，所有者自担风险，Riot 要求就删除；钢一下保持免费 |
| 1.x 数据 | 全部重来：2.0 用新的数据文件和新身份，不读 1.x 的数据（1.x 的数据文件留在原处，不删） |
| 重写方式 | 全局键鼠钩子、手势判定、队伍网络、叠层计算、设置、更新都用 Rust；轮盘、信号动画、表情、面板画在透明的 WebView 窗口里 |
| 平台 | Windows 正式支持并真机验收；macOS、Linux 照 lolPing 已跑通的做法实现，只在 GitHub Actions 上编译、跑纯逻辑测试、打包，不做真机测试，安装包和关于页注明「实验版，未测试」 |

## 4. 功能

### 4.1 信号轮盘（来自 lolPing）

- 按住触发键（Windows 和 Linux 默认 Alt，macOS 默认 ⌥ Option）用左键拖动，在按下的位置打开 8 格信号轮盘；松开时落在哪格就在按下的位置放哪个信号，带动画和原版音效。
- 只是触发键加单击（没拖动）默认照常传给下面的程序；设置里可以改成放一个「信号」。
- 被拦下的只有轮盘手势本身：拖动不会传给下面的程序（不会选中文字、拖动窗口），其余的键鼠输入一律原样放行。
- 一个全局快捷键（默认 Ctrl+Alt+P，macOS 为 ⌃⌥P）暂停和恢复。
- 设置：触发键、拖动距离、轮盘格子安排、信号大小、持续时间、音量、轮盘刻度声。
- 在队伍里时，放的信号会出现在队友屏幕上同一号显示器的同一相对位置，带你的名字。

### 4.2 表情轮盘（来自 lolPing）

- 按住另一个触发键（默认 Ctrl，macOS 为 ⌃ Control）拖动，打开 8 格表情轮盘，放英雄联盟的表情（动画加音效）。
- 可以导入自己的图片当表情，选一种出场效果；队友没有这张图时会自动从你这里拿到静态图。

### 4.3 组队（代替 1.x 的群）

- 用队伍码组队：建队伍、用队伍码进队、退出、队长解散，最多 16 人。三个平台的人可以在同一个队伍里。
- 同一局域网直接连；不在一起时经公共中继转发，内容全程加密。
- 队友的状态：在线、暂停、离开电脑、是否开着对线模式，以及走的是局域网还是中继。

### 4.4 对线模式：实时鼠标叠心之钢（2.0 新玩法）

- 用快捷键（默认 Ctrl+Alt+L，macOS 为 ⌃⌥L）或托盘开关对线模式。只有开着的人会共享鼠标位置、出现在别人屏幕上；双方都开了才能互相叠层。
- **对手就是队友的鼠标**：开着对线模式的队友，在你的屏幕上是一个跟着他鼠标实时移动的小英雄（头像、名字、生命值）。
- **700 码**：你的鼠标和他的小英雄在同一号显示器上、距离在「700 码」以内（按屏幕大小换算，见架构 6.1）。
- **充能**：在 700 码内连续待满 3 秒，对这个人充能完成；他头上的圈转满，你的心之钢图标亮起。他那边会看到「甲正在对你充能」，可以把鼠标甩开，一拉开距离充能就断。每个队友各自充能。
- **出手**：对线模式下按住信号触发键单击是「普攻」。点中充能完成的对手（落点离他当前位置足够近）就叠一层；点空了这次充能作废。
- **结果**：双方屏幕上都在他的位置爆出心之钢特效、响心之钢音效；你的层数加一，生命值按公式增长（架构 6.2）；他看到「被甲叠了一层」。
- **冷却**：同一个对手 30 秒内不能再被你叠，他头上显示倒计时。冷却期间他可以反过来追着你打。
- **团战**：几个充能完成的对手都在落点附近时，一下叠所有人（每人各算一次冷却）。
- 排行榜：队伍里每个人的层数、生命值、被叠次数。

### 4.5 Tab 队伍面板和投票（来自 lolPing）

- 在队伍里按住 Tab（不按其他修饰键）显示队伍面板：每个人的名字、状态、局域网还是中继、层数；可以静音某人、发起踢人投票。
- 投票：准备确认（全员接受才通过）、投降（七成同意）、踢人（过半同意）。每个人自己计票。
- 面板只在队伍里、没开全屏游戏时才拦 Tab；可以换成别的键，也可以关掉。

### 4.6 Alt+T 打一行字（来自 lolPing）

- 在队伍里按 Alt+T（macOS 为 ⌥T），在鼠标处弹出输入框，回车后这行字出现在队友屏幕上同一位置（或作为弹幕横穿屏幕上方，由收的人选）。最多 120 个字，几秒后消失，不保存。
- 这是对线时的一句喊话，不是聊天：没有历史记录，不能翻看。

### 4.7 控制面板（主窗口）

主窗口不再是聊天界面，改成控制面板：
- 队伍：建队伍、进队、队员列表、心之钢排行榜、退出和解散。
- 个人资料：昵称、头像（沿用 1.x 的内置头像和上传图片）。
- 设置：触发键、快捷键、轮盘编辑、表情库、对线模式、声音、外观、网络（中继）、功能开关、开机启动、自动更新。
- macOS 上缺「辅助功能」权限时，顶部显示一张卡片，带打开系统设置的按钮，并说明更新后可能要重新授权。
- 关于：版本、lolPing 致谢和 MIT 许可、Riot 素材声明。

### 4.8 常驻

- 开机可自启（默认关），常驻托盘（macOS 是菜单栏图标）；菜单：开关信号、开关对线模式、打开控制面板、检查更新、退出。
- 单实例；关闭控制面板只是收进托盘。macOS 上控制面板关闭后程序坞（Dock）里不显示图标。

### 4.9 自动更新（来自 lolPing）

- 启动时和之后每 6 小时检查一次有没有新版本（设置里可以关）；也可以在托盘菜单和关于页手动检查。
- 有新版本时在托盘和控制面板提示，显示版本号和更新说明；用户点「更新」才下载、安装、重启，不会自己突然重启。
- 下载的更新包必须通过签名校验才安装；校验不过就放弃并提示。
- 新版本发布在本项目 GitHub 仓库的 Release 里；程序只为检查和下载更新访问 GitHub。
- Windows 用安装包更新；macOS 替换整个应用；Linux 的 AppImage 能自动更新，deb 包装的提示去下载新包手动装。

## 5. 非目标（2.0 不做）

- 聊天、发图、聊天记录（1.x 有，2.0 去掉）。
- AI 队友、网页演示。
- 和 lolPing 本身互通：2.0 有自己的队伍协议，不能和 lolPing 用户组队。
- 读取或改动英雄联盟客户端：和 lolPing 一样，只是桌面玩具。
- 打洞直连：跨网仍走公共中继，对线模式跨网时会比局域网卡一些（见架构 6.3）。
- Linux 的 Wayland 会话（全局键鼠在 Wayland 下拿不到）、Intel 芯片的 Mac、ARM 的 Windows 和 Linux、应用商店上架。
- 付费的代码签名和苹果公证（除非所有者另行决定，见 8）。

## 6. 平台和限制

| 平台 | 状态 | 支持范围 | 主要限制 |
|---|---|---|---|
| Windows | 正式支持，真机验收 | Windows 10/11 64 位 | 以管理员身份运行的窗口（如任务管理器）收不到钩子；安装包没有签名，第一次运行 SmartScreen 会拦，要点「仍要运行」 |
| macOS | 实验版，未测试 | macOS 13 以上，Apple 芯片（M1 及以后） | 要在「隐私与安全性 → 辅助功能」里授权；没有苹果开发者签名，第一次打开要在「隐私与安全性」里点「仍要打开」，每次更新后要重新授权辅助功能 |
| Linux | 实验版，未测试 | 64 位、X11 会话（如「Ubuntu on Xorg」），需要窗口合成器 | 不支持 Wayland；GNOME 需要 AppIndicator 扩展才显示托盘；有的窗口管理器自己占用 Alt+拖动，要换触发键；不自动识别全屏游戏 |

「实验版，未测试」的意思：代码照 lolPing 在这两个平台上已经跑通的做法写，GitHub Actions 能编译、纯逻辑测试能过、能打出安装包，但没有人在真机上用过，可能有问题。安装包文件名不变，关于页和 README 写明这一点。

三个平台共同的限制：独占全屏的游戏会盖住透明窗口，游戏用无边框窗口模式才看得见信号和对手；只捕获单个窗口的截图和直播拍不到信号，整屏捕获可以。

## 7. 验收

1. 触发键+拖动在浏览器、文件管理器、VS Code、Discord 上打开轮盘，下面的程序收不到拖动；不开轮盘时一切输入照常。
2. 松开到信号上，动画和声音立刻出现；两台电脑在同一队伍时，对方屏幕同一位置出现同一信号。
3. 表情轮盘同样可用；导入的图片表情能传给没有这张图的队友。
4. 两人都开对线模式：能看到彼此的鼠标小英雄；贴近 3 秒充能，对方屏幕有提示，对方甩开充能就断；充满后普攻命中叠一层，双方都有特效和音效；30 秒冷却生效；两边的层数和生命值一致。
5. 局域网和跨网（一台用手机热点）各验一遍 2 和 4。
6. Tab 面板、准备确认投票、Alt+T 打字在两台电脑上可用。
7. 暂停快捷键能立即停掉所有拦截；程序退出或崩溃后键鼠完全正常。
8. 安装包能装能卸，卸载后不留钩子。
9. macOS 和 Linux：GitHub Actions 上编译通过、纯逻辑测试通过（Linux 另跑 Xvfb 里的输入集成测试）、产出安装包。不做真机验收。
10. 自动更新（在 Windows 上验）：装旧版本，发布新版本后旧版本能发现、下载、校验并更新到新版本；签名不对的更新包被拒绝。macOS 和 Linux 的更新包照样生成，不验。

## 8. 需要所有者提供或决定

- **GitHub 仓库**：发布更新用的仓库地址（公开仓库，更新包放在 Release 里）。
- **更新签名密钥**：由所有者生成并保管，私钥只放在 GitHub 仓库的 Secrets 里，不进代码库、不发给任何人。
- 不买苹果开发者账号，macOS 实验版按 6 节的限制发布。
